# MARS // Engineering Archive

A retro Mars/NASA-inspired personal engineering site designed for GitHub Pages.

## Files

- `index.html` — site structure/content
- `style.css` — visual design and responsive layout
- `script.js` — mission clock and small interactions

## Deploy to GitHub Pages

1. Create a GitHub repository, for example `mars-archive`.
2. Upload these three files to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save. GitHub will provide the Pages URL.

## Customize

Search `index.html` for:
- `ESTEBAN DURAN`
- project descriptions
- engineering log entries
- navigation links

Replace placeholder `href="#"` project/log links with your real GitHub URLs or article pages.
